覆盖持续识别、原生草稿、会话执行和语音播放。
01 — MAIN PIPELINE / 主链路

识别结果如何进入会话

空闲 · 草稿为空识别语段先合并，等待续说窗口结束，再通过原生输入框自动提交。
推理或播报期间新语音先合并到原生草稿；满足租约、停留时间与门控条件后续发。
用户编辑或门控失败撤销自动发送，保留文字供人工处理；敏感文本及声纹异常不自动提交。

控制规则与职责边界

打断与取消普通插话进入草稿；明确取消口令才取消 Harness 任务。播放打断需防回声复核。
结果播报从可见回答的第一段提取口语结果，流式交给 TTS；不朗读 reasoning 或工具细节。
唯一推理入口语音层不自行回答或执行业务工具；推理、工具调度和正式历史由 Harness 负责。

Client · 浏览器麦克风采集、原生输入框、轨迹观察、播放和交互状态。
Host · 执行边界同源信令 / WebSocket 代理与凭据读取；Key 不进入浏览器。
Provider · 语音服务ASR 只负责识别，TTS 只负责合成。连接可持续处理多个语段。
